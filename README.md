# Компьютерное зрение для БПЛА

Демонстрационный стенд обрабатывает поток с веб-камеры или видео. В режиме YOLO используется предобученная [YOLOv8n](https://docs.ultralytics.com/models/yolov8/) с порогом уверенности 0,5. В режиме Color OpenCV выделяет самый крупный красный контур по цветовым порогам HSV.

Решение строится по двум признакам. Координата центра рамки определяет треть кадра, а площадь рамки в пикселях задаёт условный уровень риска. При высоком уровне риска подсказка меняется на `STOP`. Рамка, зона и подсказка видны в окне OpenCV. Команды используются только для визуализации.

## Запуск

Понадобятся Python 3.12 и графическое окружение. Первый запуск YOLO загружает веса модели. Режим Color можно запустить без скачивания весов.

```bash
python3.12 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
python main.py
```

Для проверки на своём видео или красном объекте используй, например, `python main.py --source video.mp4 --detector color`. Клавиша `q` закрывает окна.

Площадь рамки зависит от разрешения кадра и физического размера объекта. Пороги демонстрируют логику подсказок и требуют калибровки для каждой камеры и задачи. Система не оценивалась в полёте.
